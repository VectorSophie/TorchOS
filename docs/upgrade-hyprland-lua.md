# Existing installations: moving a user to the Hyprland Lua config

Hyprland 0.57 reads only `~/.config/hypr/hyprland.lua`. TorchOS ships its desktop config in `torch-config` as
`/etc/skel/.config/hypr/` (`hyprland.lua`, `bindings.lua`, `local.lua`), which is copied into a home directory only
when an account is created. Accounts created before this change keep the old `hyprland.conf` (now ignored) and,
after updating to Hyprland 0.57, an autogenerated stock `hyprland.lua`. Nothing updates them automatically: TorchOS
does not overwrite files in a home directory. Run the steps below as that user, in a terminal.

What changed besides the file format:
- `conf.d/*.conf` overrides are replaced by one file, `local.lua`, loaded last and never overwritten by TorchOS.
- `hyprctl dispatch` takes Lua now, so `hypridle.conf` (screen off/on) and `~/.config/wlogout/layout` (Logout)
  changed too: `hyprctl dispatch 'hl.dsp.dpms({ action = "disable" })'`, `hyprctl dispatch 'hl.dsp.exit()'`.

## 1. Preview

```bash
diff -ru ~/.config/hypr /etc/skel/.config/hypr
diff -u ~/.config/wlogout/layout /etc/skel/.config/wlogout/layout
```

Lines only in `~/.config/hypr` that you wrote yourself (in `hyprland.conf`, `bindings.conf` or `conf.d/`) will not
carry over by themselves: note them for step 4.

## 2. Keep the original

```bash
cp -a ~/.config/hypr ~/.config/hypr.pre-lua-$(date +%Y%m%d-%H%M%S)
cp -a ~/.config/wlogout ~/.config/wlogout.pre-lua-$(date +%Y%m%d-%H%M%S)
```

## 3. Install the TorchOS config

```bash
install -m644 /etc/skel/.config/hypr/hyprland.lua /etc/skel/.config/hypr/bindings.lua ~/.config/hypr/
[ -e ~/.config/hypr/local.lua ] || install -m644 /etc/skel/.config/hypr/local.lua ~/.config/hypr/
```

For `hypridle.conf` and `wlogout/layout`: if step 1 showed no changes of your own, copy them from `/etc/skel/.config`
the same way; otherwise change only their `hyprctl dispatch …` lines to the Lua form shown above.

## 4. Your own settings

Translate what you noted in step 1 into `~/.config/hypr/local.lua`; it has examples. Syntax and options:
`/usr/share/hypr/stubs/hl.meta.lua`, https://wiki.hypr.land/configuring/. The old `.conf` files can stay (Hyprland
ignores them) or be deleted; the backup from step 2 has them either way.

## 5. Check, then log in again

```bash
Hyprland --verify-config -c ~/.config/hypr/hyprland.lua    # must end with "config ok"
```

Log out and back in: the bar, notifications and idle lock start once per Hyprland start, not on a config reload.
`hyprctl configerrors` should print nothing. To go back: restore the `*.pre-lua-*` copies.
